# Popsmon Adventure (Legend of Popselion )
*A retro terminal RPG where creatures battle using elemental powers*

## Story
- COMING SOON!

## Overview  

- Popsmon Adventure is a text‑based, Pokémon‑inspired RPG built entirely in C++. You explore the "world", encounter wild Popsmon, choose strategic moves in battle, and build a team of unique elemental creatures. The game runs directly in the terminal and embraces a nostalgic retro style.

## Features
- Retro Title Screen and classic menu navigation
- Turn‑Based Battles with move selection
- Elemental Type System (Fire, Water, Nature, Electric, Earth, Wind, Shadow, Light, Psychic, Infinity)
- Switch Popsmon mid‑battle
- Random Wild Encounters
- Simple, fast damage system for snappy gameplay
- View Your Party at any time

## Tech
- Written in C++
- Modular architecture (Game, Player, Popsmon, Popsopedia, TypeChart, Damage)
- Fully terminal‑based
